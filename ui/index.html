TOOL ACCESS

Register tools without running them

Tool folders expose matching executables and scripts to find_tool. Documentation is included by default, so the agent can search and fetch a nearby README.md before using a tool.

Discovery only The MCP server verifies and returns local paths. It never launches a program, changes PATH, or treats discovery as permission to execute.

SECRET ACCESS

Register exact credential files

Each grant is one file, never a folder. The UI detects key names such as hostname and password, but it never displays or stores their values.

Explicit access only Secret files are excluded from document search, fetch, and tool discovery. find_secret returns metadata; read_secret releases only explicitly requested fields. Prefer giving a program the file path whenever it supports an environment-file or key-file option.
