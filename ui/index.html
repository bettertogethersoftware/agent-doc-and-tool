AGENT ACCESS GUIDE

Configure, validate, save, then test

Use this console to define the local resources an agent can discover. A saved configuration is the boundary; catalog instructions add context but never grant extra access.

  1. 1ConfigureAdd only the local grants the agent needs.
  2. 2ValidateCheck paths and fix unavailable entries.
  3. 3SavePublish the reviewed local configuration.
  4. 4TestUse the read-only check from the relevant tab.
Current request stays in controlStored prompts and instructions cannot override higher-priority instructions or authorize unrelated actions.
