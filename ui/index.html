PROMPT HELP

Use reusable prompts safely

The Prompts tab stores named reusable text. list_prompt inventories enabled names and keywords, find_prompt narrows the selection, and read_prompt retrieves only the chosen full prompt.

Current request stays in control A stored prompt supplies reusable task details. It cannot override higher-priority instructions or authorize unrelated actions.

DOCUMENT HELP

Search only approved local documents

The Documents tab registers recursive folders and exact files. list inventories enabled grants, search scans all enabled grants or selected names, and fetch reads one returned absolute path.

Read-only and allowlisted Document tools do not index, write, or search outside enabled grants. Registered secret files are always excluded.

TOOL HELP

Discover tools before running them

The Tools tab registers folders, exact files, Folder Instructions, and saved scan selections. list_tool inventories enabled grants first; find_tool resolves a matching local path only when needed. Included documentation can be searched and fetched before use.

Discovery is not execution The MCP server returns local paths. It never launches a program, changes PATH, or treats discovery as permission to execute.

SECRET HELP

Grant exact credential files carefully

The Secrets tab accepts exact files only. list_secret inventories enabled aliases and paths without opening them, find_secret returns field metadata, and read_secret releases only explicitly requested fields.

Explicit access only Secret files are excluded from document search, fetch, and tool discovery. Prefer giving a program the file path whenever it supports an environment-file or key-file option.
